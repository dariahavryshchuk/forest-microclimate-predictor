**FILE NAMES AND CONTENTS**
Processed_microclimate_data.csv
- Daily maximum and minimum temperature, relative humidity, and vapor pressure deficit for each sensor summarized from 30 minute readings. 


**FILE STRUCTURE AND UNITS OF MEASUREMENTS**

The file is a comma delimited file.
Column headings are in the following order and format:

Sensor
 - Name of the temperature/RH sensor. Name includes 3 letter code for location, site elevation, subplot number, and sensor height.

Subplot
 - Subplot name (each subplot had two sensors, one at each height as described below).

Site
 - The site name, includes the 3 letter code for the location and whether it was the high or low elevation site. See manuscript for site elevations.

SensorHeight
 - Height of the temperature/RH sensor. "Low" was 10 cm from ground and "High" was 2 m from ground.

Location
 - Location name. Within each location there was a high and low elevation site. Within each site there were 6 subplots. 

Date
 - Date that temperature/RH data were recorded.

MaxTemp
 - Maximum daily temperature in degrees C.

MinTemp
 - Minimum daily temperature in degrees C.

MaxRH
 - Maximum daily relative humidity (%).

MinRH
 - Minimum daily relative humidity (%).

MaxVPD
 - Maximum daily vapor pressure deficit in kPa. VPD was calculated for every 30 minute reading from the initial temperature and humidity readings and then the maximum for the day was recorded. 

MinVPD
 - Minimum daily vapor pressure deficit in kPa. VPD was calculated for every 30 minute reading from the initial temperature and humidity readings and then the minimum for the day was recorded. 

Canopy
 - Percent canopy cover at the point of the sensor. 

MetMaxTemp
 - Maximum temperature (degrees C) of the sensor in the clearing (0% canopy cover) at the same site, same sensor height, and same day. 

MetMinTemp
 - Minimum temperature (degrees C) of the sensor in the clearing (0% canopy cover) at the same site, same sensor height, and same day. 

MetMaxRH
 - Maximum relative humidity (%) of the sensor in the clearing (0% canopy cover) at the same site, same sensor height, and same day. 

MetMinRH
 - Minimum relative humidity (%) of the sensor in the clearing (0% canopy cover) at the same site, same sensor height, and same day. 

MetMaxVPD
 - Maximum VPD (kPa) of the sensor in the clearing (0% canopy cover) at the same site, same sensor height, and same day. Calculated the in the same way as MaxVPD at each sensor. 

MetMinVPD
 - Minimum VPD (kPa) of the sensor in the clearing (0% canopy cover) at the same site, same sensor height, and same day. Calculated the in the same way as MinVPD at each sensor
